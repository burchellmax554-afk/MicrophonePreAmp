This project is a custom microphone pre-amplifier designed and assembled using KiCad for PCB layout and schematic development. The board was created to amplify low-level microphone 
signals into a much stronger and more usable audio output. The design includes analog amplification stages, passive filtering components, and dedicated input/output connections to 
support clean signal transfer across the circuit.

After completing the PCB layout, the board was assembled and soldered by hand using resistors, amplifiers, switches, and supporting circuitry. Testing confirmed that the circuit 
successfully increased microphone volume while maintaining understandable and coherent audio quality, even when using inexpensive microphones and speakers. The project provided 
hands-on experience with PCB design, signal routing, soldering, circuit debugging, and audio electronics validation.
